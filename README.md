# Task-Scoped Pseudonymization for LLM Security Alert Correlation

This repository contains the implementation and evaluation scripts for evaluating task-scoped pseudonymization in LLM-based security log analysis.

## Requirements
- Python 3.10+
- openai, matplotlib, scipy

## Usage
python scripts/eval_utility.py
python scripts/privacy_audit.py
python scripts/plot_tradeoff.py
